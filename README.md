# 天門 (CHEONMUN) — 정통 사주명리학 & 칼 융 분석심리 타로 살롱

> **"정해진 운명의 거시적 흐름을 읽고, 내면의 무의식을 비추어 주체적 삶을 선택합니다."**

3,000년 정통 자평진전 명리학과 칼 구스타프 융의 78장 아르카나 무의식 타로를 결합한 프리미엄 운명 상담 웹 플랫폼입니다.

---

## 운영사업자 정보 관리

- 천문 서비스브랜드는 유지하며 운영사업자는 벅스라이프, 대표자 염동화입니다.
- 메인·사주·타로 푸터와 루트·서비스별 약관/개인정보처리방침/환불정책의 사업자정보를 함께 관리합니다.
- 사업자등록번호와 사업장 주소는 제공된 사업자등록증명 원본과 대조했습니다. 원본 이미지와 개인식별정보는 저장소에 포함하지 않습니다.
- 통신판매업신고번호는 확인 전 게시하지 않습니다. 기존 문의 채널의 실제 운영 여부와 추가 업종 승인 여부는 별도 확인 대상입니다.
- 정적 HTML/CSS/JS 프로젝트로 별도 빌드 명령은 없습니다. 아래 로컬 실행 방법으로 화면을 확인합니다.
- 이번 변경은 12개 HTML의 정보 일치, 기존 스크립트·스타일·링크·사업자 식별 외 약관 본문 보존 및 1280/768/390/360px 브라우저 화면을 검증합니다.

## 정적 자산 경로와 회귀 검사

- Vercel의 확장자 없는 URL과 슬래시/별칭에서도 같은 파일을 읽도록 서비스 HTML의 자산·탐색 경로를 `/1/...`, `/2/...` 기준으로 고정합니다.
- 타로 덱·보드·리포트가 공유하는 카드 이미지 경로도 `/2/assets/cards/...`를 사용합니다. CSS 내부 URL은 스타일 파일 기준으로 해석됩니다.
- 루트와 두 서비스의 동일한 정책 템플릿은 공통 `/1/style.css`를 사용합니다. 타로 서비스 자체는 `/2/style.css`를 유지합니다.
- 전체 회귀 검사: `python -B -m unittest discover -s tests -v`. 추가 패키지가 필요하지 않습니다.
- 검사 범위: 39개 직접/슬래시/별칭 URL 조합의 자산·탐색 대상, 타로 카드 앞뒷면 79개, CSS 내부 자산. 브라우저에서는 1280/768/390/360px, 사주 화면 전환, 타로 셔플·카드 앞면, 정책 복귀와 서비스 간 이동을 확인합니다.
- 사업자정보·약관 본문·분석/결제 로직·CSS 디자인·Vercel 라우팅 설정은 이 경로 수정에서 변경하지 않습니다.

## ✨ 핵심 기능 명세

### 1. 천문(天文) 사주명리학 (`/1/`)
- **정통 자평진전 10정격 만세력**: 생년월일시 기준 천간·지지 8글자, 득령·득지·득세 기반 신강/신약 정밀 판정.
- **87페이지 조선 왕실 목판본 A4 PDF 발급**: 한지 질감의 고서적 디자인, 목차, 4대 카테고리(이직·취업, 연애·궁합, 신년운세, 재물운) 심층 풀이.
- **의명진단학(醫命診斷學) 체질 처방**: 8글자 오행 편고에 따른 장부 건강 및 맞춤 식재료, 추천 여행지, 액티비티 가이드.
- **성인사주 19+ 무드 솔루션**: 두 사람의 오행 합충 및 체질에 맞춘 침실 무드와 솔루션.

### 2. 천문(天文) 심리 타로 살롱 (`/2/`)
- **1인칭 인터랙티브 3D 부채꼴 덱 (Fan Deck)**: 78장의 카드가 아크 형태로 펼쳐지며 마우스/터치로 직접 카드를 선택.
- **4대 정통 스프레드 & 3D 플립 보드**: 켈틱 크로스(10카드), 3카드 시간선/심리구조, 양자택일 5카드, 원카드.
- **4원소 조화도 (Elemental Dignities)**: 불(직관)·물(감정)·공기(사고)·흙(감각)의 상호작용 및 사주 오행 크로스 분석.
- **칼 융 분석심리학 3단계 촌철살인 리포트**:
  - STEP 1: 깊은 공감과 감정의 반영 (Validation)
  - STEP 2: 뼈를 때리는 맹점 조명과 무의식 직면 (*"과연 '못' 가는 걸까, '안' 가는 걸까?"*)
  - STEP 3: 주체적 3대 현실 실천 지침 (Actionable Roadmap)
- **14페이지 완벽 규격의 A4 소장용 타로 감명서 PDF 발급**: 최종 신탁 어인(天門之印) 칙서 수록.

## 🔒 전자상거래 및 결제(PG) 적합성 준수

- **토스페이먼츠 / 포트원 안전결제 연동**: 신용·체크카드, 카카오페이, 네이버페이, 토스페이 지원.
- **전자상거래법 필수 고지 완비**:
  - 푸터 사업자 정보 (상호, 대표자, 사업자번호, 통신판매업신고번호, 사업장 소재지, 고객센터).
  - 이용약관(`terms.html`), 개인정보처리방침(`privacy.html`), 환불정책(`refund.html`) 전 페이지 수록.
  - 디지털 콘텐츠 열람 개시 전 청약철회 제한 필수 동의 체크박스 적용.
